# 🛍️ Zestify – E-Commerce Website

Zestify is a responsive e-commerce website designed with a modern, Gen-Z-friendly shopping experience.

### 🚀 Features

* Responsive design using Bootstrap 5
* Product and category sections
* Interactive shopping cart counter
* Add-to-cart functionality
* Newsletter subscription
* Email validation
* Mobile-friendly layout

### 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Bootstrap 5.3.3

### 📁 Project Structure

```text
zestify-ecommerce/
├── Admin
├── Zestify
└── Backend
```

### ▶️ Run Locally

Clone the repository and open `index.html` in your browser.
